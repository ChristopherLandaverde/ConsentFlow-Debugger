ConsentFlow measurement checklist

Use the website measurement playground to verify these GA4 enhanced-measurement events.

  1. Load the page for page_view.
  2. Use the SPA control for a history-based page_view.
  3. Reach the bottom marker for scroll.
  4. Open the external Analytics help link for click.
  5. Submit a fixed search term for view_search_results.
  6. Play the embedded YouTube video for video_start.
  7. Download this checklist for file_download.
  8. Use the fixed scenario form for form_start and form_submit.

Use only non-sensitive test choices. Confirm collection through browser requests before making any reporting claim.
